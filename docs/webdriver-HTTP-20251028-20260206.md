# WebDriver Spec Changes: 20251028 → 20260206

Comparing:
- https://www.w3.org/TR/2025/WD-webdriver2-20251028/
- https://www.w3.org/TR/2026/WD-webdriver2-20260206/

Grammar and typo fixes excluded.

---

## 1. [§ 15.5 Process a pointer move action](https://www.w3.org/TR/2026/WD-webdriver2-20260206/#dfn-process-a-pointer-move-action) — x/y coordinate type widened

- **2025**: `x` and `y` must be an **Integer** → error if not
- **2026**: `x` and `y` must be a **Number** → error if not

Floating-point pointer coordinates are now permitted.

---

## 2. [§ 15.5 Process a pointer move action](https://www.w3.org/TR/2026/WD-webdriver2-20260206/#dfn-process-a-pointer-move-action) — origin validation logic changed

- **2025**: `"If origin is not equal to "viewport", or actions options' is element origin steps given origin return false, return error"`
  → logic: `(origin ≠ "viewport") OR (element_check = false)`
- **2026**: `"If origin is not equal to "viewport" or "pointer", and actions options is element origin steps given origin return false, return error"`
  → logic: `(origin ≠ "viewport" AND origin ≠ "pointer") AND (element_check = false)`

**`"pointer"` is now explicitly a valid origin value** that bypasses the element-origin check.

---

## 3. [§ 7.2 Processing capabilities](https://www.w3.org/TR/2026/WD-webdriver2-20260206/#processing-capabilities) — new standard matched capabilities table

The 2026 spec adds an explicit listing of the standard capabilities returned in matched capabilities:

| Capability                  | Description                                         |
| --------------------------- | --------------------------------------------------- |
| `platformName`              | ASCII Lowercase platform name string                |
| `acceptInsecureCerts`       | Boolean, default false                              |
| `strictFileInteractability` | Boolean, default false                              |
| `setWindowRect`             | Boolean — whether resizing/positioning is supported |
| `userAgent`                 | String — the default User-Agent value               |

A second `strictFileInteractability` entry is also added specifically when the `http` session configuration flag is set.

---

## 4. [§ E.1 Index of defined terms](https://www.w3.org/TR/2026/WD-webdriver2-20260206/#index-defined-here) — many new formally defined terms

The 2026 index adds numerous newly defined terms, including:

- `Candidate for constraint validation`
- `Canvas context mode`
- `capabilities`, `capability name`
- `Checkbox`, `Checked`, `Checkedness`, `Child browsing context`
- `clear a content editable element`, `clear a resettable element`, `clear algorithm`
- `clear the modifier key state`, `click event`
- `Close a browsing context`, `close the session`
- `Compute cookie-string`, `compute the tick duration`, `Computed value`
- `connection`, `container`, `Content editable`
- `interactable element`, `Intermediary node`

These represent the formalization of previously implicit concepts.
